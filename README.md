Freshly Restaurant — Site Web HTML/CSS/JS

Description du projet :

Site web vitrine d'un restaurant fictif "Freshly Restaurant", développé en HTML5, CSS3 et JavaScript pur. 
Projet d'intégration web front-end complet avec 4 pages, animations, slider d'images, vidéo et filtres interactifs sur les menus.

Fonctionnalités :

- Page d'accueil
- Slider d'images automatique (Slick.js)
- Section de présentation du restaurant
- Aperçu des menus spéciaux (Viande, Poisson, Végétarien) avec prix
- Navigation responsive

Page À propos :

- Présentation du restaurant et de son histoire
- Vidéo de cuisine avec poster
- Galerie des salles privées (4 espaces)

Page Menus :

Affichage de tous les plats avec photos

Filtres interactifs animés (MixItUp.js) :

- Tous les plats
- Viande
- Vegan
- Poisson

Page Contact :

Formulaire de réservation avec champs requis :

- Date
- Heure
- Nombre de convives
- Informations personnelles

Stack technique :

Outil Usage HTML5, Structure sémantique (header, nav, main, section, article, figure...)
CSS3 Mise en page, animations, responsive design
JavaScript Interactions et plugins.
